# 🏙️ Civic Issue Tracker 

A backend system for a civic issue reporting platform that allows citizens to report local problems like potholes, garbage issues, streetlight failures, and track their resolution status in real time.

The system is designed to help local authorities manage and resolve public issues efficiently using a structured workflow.

---

## 🚀 Key Features

- User registration and login system with secure authentication
- Role-based access (normal users and administrators)
- Citizens can report civic issues with details
- Authorities can update issue status (pending → in progress → resolved)
- Secure password protection using encryption
- RESTful APIs for smooth communication between frontend and backend
- Clean and modular backend architecture for scalability

---

## 🛠️ Tech Stack

- Node.js (server-side runtime)
- Express.js (backend framework)
- MongoDB (database for storing users and issues)
- JSON Web Tokens (secure login sessions)
- bcrypt.js (password encryption)
- dotenv (environment variable management)
